# Guías de integrantes

Cada guía define alcance, archivos, contratos, orden de trabajo, pruebas y
criterios de aceptación. Las rutas pueden ampliarse, pero no se deben invadir
responsabilidades de otro módulo.

1. [Tablero y casillas](integrante_1_tablero.md)
2. [Piezas y reglas](integrante_2_piezas.md)
3. [Motor de simulación](integrante_3_simulacion.md)
4. [Biomas e interfaz](integrante_4_biomas_ui.md)
5. [Integración y progresión](integrante_5_integracion.md)

Todo cambio se entrega en una rama propia y Pull Request hacia `develop`, con
pruebas reproducibles y archivos afectados enumerados.
